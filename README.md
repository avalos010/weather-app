# 🌤️ Modern Weather App

A beautiful, modern weather application built with vanilla JavaScript, Tailwind CSS, and modern web technologies.

## ✨ Features

- **Modern UI Design**: Beautiful gradient backgrounds with glassmorphism effects
- **Real-time Weather Data**: Current weather information based on your location
- **Responsive Design**: Works perfectly on all devices
- **Smooth Animations**: Elegant entrance animations and hover effects
- **Weather Icons**: Dynamic FontAwesome icons that change based on weather conditions
- **Additional Weather Info**: Temperature, humidity, wind speed, and "feels like" temperature
- **Error Handling**: Graceful error handling with retry functionality
- **Accessibility**: High contrast mode and dark mode support

## 🚀 Getting Started

### Prerequisites

- Modern web browser with geolocation support
- Node.js (optional, for development)

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd modern-weather-app
```

2. Install dependencies (optional):
```bash
npm install
```

3. Open `index.html` in your browser or use the development server:
```bash
npm start
```

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Custom animations and responsive design
- **Tailwind CSS**: Utility-first CSS framework
- **Vanilla JavaScript**: Modern ES6+ features, no jQuery dependency
- **FontAwesome**: Beautiful weather icons
- **Google Fonts**: Inter font family for modern typography

## 🎨 Design Features

- **Glassmorphism**: Semi-transparent cards with backdrop blur effects
- **Gradient Backgrounds**: Beautiful blue to purple gradients
- **Responsive Grid Layout**: Adapts to different screen sizes
- **Smooth Transitions**: CSS transitions and animations throughout
- **Modern Typography**: Clean, readable font hierarchy
- **Icon Integration**: Contextual weather icons with custom colors

## 📱 Responsive Design

The app is fully responsive and works on:
